## Pipeline Studio

**One line** — A visual CI/CD pipeline builder: drag stages onto a canvas, wire
approval gates between them, and watch a simulated deployment run through it.

**Why it fits** — Stands in for the Harness continuous-deployment UI: rollback,
approval gates, infrastructure definitions. Her most distinctive professional
work and the least visible.

**Stack** — React + Vite + TypeScript, XState for run simulation, SVG canvas.

**Scope**
- Drag-and-drop stage canvas with typed connections
- Stage kinds: build, deploy, approval gate, rollback
- "Run" plays the pipeline through, stage by stage, with live status
- Failure injection — click a stage to fail it and watch rollback trigger
- Out: real integrations, persistence beyond localStorage

**First paint** — A populated four-stage pipeline mid-run, one stage green, one
amber, gate pending.

**Effort** — L, roughly 14–18h

**Status** — `new`
